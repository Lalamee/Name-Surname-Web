## 📌 Описание проекта

Консольное приложение на Python, которое моделирует работу супермаркета:

- Магазин хранит **каталог товаров** (товаров считаем бесконечное количество).
- Есть **очередь клиентов** (реализована обычным списком).
- При обслуживании клиента проверяется, хватает ли денег на товары в корзине.
  - Если денег не хватает — клиент **случайно выкидывает товары из корзины**, пока сумма не станет доступной (или корзина не опустеет).
  - Если корзина опустела — клиент уходит без покупок.
  - Если хватает — клиент покупает все оставшиеся товары, а магазин увеличивает прибыль.

---

## 🚀 Функциональность
- Добавление товаров в каталог при запуске (название + цена)
- Добавление клиента в очередь
- Обслуживание следующего клиента из очереди
- Просмотр каталога товаров
- Просмотр прибыли магазина (статистика)
