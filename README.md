## 📌 Описание проекта

Консольное приложение на Python, которое моделирует работу супермаркета:

- Магазин хранит **каталог товаров** (товаров считаем бесконечное количество).
- Есть **очередь клиентов** (реализована обычным списком).
- При обслуживании клиента проверяется, хватает ли денег на товары в корзине:
  - если денег не хватает — клиент **случайно выкидывает товары из корзины**, пока сумма не станет доступной (или корзина не опустеет);
  - если корзина опустела — клиент уходит без покупок;
  - если денег хватает — клиент покупает все оставшиеся товары, а магазин увеличивает прибыль.

## 🚀 Функциональность
- Добавление товаров в каталог при запуске (название + цена)
- Добавление клиентов в очередь
- Обслуживание клиентов по очереди (первый пришёл — первый обслужен)
- Автоматическое «удаление» случайных товаров из корзины, если денег не хватает
- Просмотр каталога товаров
- Просмотр прибыли магазина (статистика)

## 🧭 Как пользоваться

### 1) Добавление товаров
После запуска программа предложит добавить товары в каталог:
- количество товаров;
- для каждого товара: **название** и **цена**.

> В каталоге товары считаются бесконечными: если 10 клиентов купят «хлеб», он не закончится.

### 2) Меню программы
Дальше появится консольное меню с действиями:
- добавить клиента в очередь;
- обслужить следующего клиента;
- показать каталог;
- показать статистику/прибыль;
- выход.

### 3) Добавление клиента
При добавлении клиента обычно вводятся:
- имя клиента;
- количество денег;
- товары в корзину (обычно через запятую).

Если какого-то товара нет в каталоге — он не добавляется в корзину.

### 4) Обслуживание клиента
При обслуживании:
- если денег не хватает — из корзины удаляются случайные товары, пока покупка не станет возможной;
- если корзина стала пустой — клиент уходит без покупок;
- если покупка возможна — товары переходят в сумку клиента, деньги списываются, прибыль магазина увеличивается.

## 📁 Структура проекта
- `Main.py` — запуск программы и меню
- `Supermarket.py` — логика магазина (каталог, очередь, прибыль, обслуживание)
- `Client.py` — логика клиента (корзина, подсчёт суммы, покупка)
- `Product.py` — товар (название, цена)
